ISO inject that worked
Stock proxmox-ve 9.2 grub already has a serial menu entry, but it is
hidden unless grub can probe a serial port. Rescue kvm has no VGA
(-nographic, no -vnc), so the probe does not run and that entry never
shows. The injected grub.cfg forces the serial terminal and defaults
to "Install Proxmox VE (Terminal UI, Serial Console)" with timeout 10.
See grub-stock.cfg and grub-serial.cfg.

xorriso -boot_image any replay failed on this ISO (xorriso 1.5.6):
  GPT partitions 1 and 2 overlap by 80 blocks
  xorriso SORRY 32
That is the isohybrid layout. Log: xorriso.txt. Do not retry replay.

What worked, from the Proxmox auto-install note (keep the volume uuid
so the boot image still finds its partition):
  xorriso -dev ISO -report_system_area cmd
  uuid 2026052111373600
  cp ISO ISO-serial
  xorriso --boot_image any keep -volume_date uuid 2026052111373600 \
    -dev ISO-serial -map grub-serial.cfg /boot/grub/grub.cfg
Log: xorriso-keep.txt. Re-extracted cfg contains the set default= line.
